# PopClip UpNote Extension (增強版)

PopClip 的 UpNote 擴充功能增強版。除了建立新筆記外，還支援**直接空一行插入特定筆記**以及**建立新筆記至指定筆記本**。

---

## ✨ 功能亮點

1. **UpNote 新筆記**：
   - 選取文字後一鍵建立新筆記。
   - 瀏覽器中選取文字自動附帶網頁來源連結。
2. **UpNote 插入特定筆記**：
   - 自動跳轉至指定筆記，**直接空一行插入**於最末端。
   - 支援可選的時間戳記（如 `- 14:30`）。
3. **UpNote 新增到特定筆記本**：
   - 直接將內容在指定的筆記本（或子筆記本）中新增為獨立筆記。

---

## 🚀 安裝方式

### 方法一：直接下載安裝套件（最推薦）
1. 在本專案的 [Releases 頁面](https://github.com/houtacheng/popclip-upnote/releases) 下載最新版的 `UpNote.popclipextz`。
2. 下載後雙擊該檔案，PopClip 即會彈出提示點擊「安裝」即可！

### 方法二：手動安裝
1. 將本專案中的 `UpNote.popclipext` 資料夾複製至您的 PopClip 擴充功能目錄。

---

## ⚙️ 設定說明

在 PopClip 偏好設定中點選 **擴充功能 -> UpNote**：

1. **特定筆記連結或 ID**：
   - 在 UpNote 中對目標筆記按右鍵，點擊「複製筆記連結」。
   - 直接貼入此欄位（支援 `upnote://x-callback-url/openNote?noteId=...` 或純筆記 ID）。
2. **特定筆記本名稱**：
   - 填入目標筆記本名稱（例如 `工作` 或 `日誌`）。
3. **包含來源網址**：從瀏覽器選取文字時自動在文末附上網址（預設開啟）。
4. **包含時間戳記**：在插入或新增的文字開頭加上時間（預設關閉）。
